# Штурвал – презентация

Интерактивная презентация Enterprise Kubernetes-платформы «Штурвал» от «Лаборатории Числитель». Рассчитана на первую встречу с заказчиком: технических специалистов и их руководителей.

**Открыть:** https://pinkkoff.github.io/shturval-main-deck/

## Управление

| Действие | Как |
|---|---|
| Следующий / предыдущий слайд | ← →, пробел, клик по правой или левой половине слайда, свайп |
| В начало / в конец | Home / End |
| Полный экран | F или кнопка ⤢ |
| Скрыть слайд с логотипами заказчиков | L или кнопка «Логотипы» |
| Подсказка по клавишам | ? |

Ссылка на конкретный слайд – номер или идентификатор после `#`, например `#16` или `#tco`. Параметр `?nologos` открывает презентацию сразу без слайда с логотипами заказчиков.

## Что внутри

1. Кто мы, что такое Штурвал, короткое резюме для руководителя.
2. **Enterprise во всём:** четыре свойства, архитектура, работа с инфраструктурой, мультиЦОД и DR, изолированные сегменты, автоматизации, кейс Почта Банка, безопасность.
3. **ML / AI:** ML-стек, общий пул GPU, LLM и инференс.
4. **Vendor-agnostic:** чего у Штурвала нет, совместимость.
5. **Лучшее TCO:** из чего складываются затраты, расчёт на 5 лет, Community Edition.
6. Рынок, рост, заказчики, лицензирование, следующие шаги.

На слайдах 4, 7, 12, 16 и 18 – живые экраны интерфейса Штурвала: в них можно переключать вкладки, режимы и состояния.

## Печать в PDF

Cmd+P (Ctrl+P), формат страницы задан в презентации: 1920×1080, фон печатается. Скрытые слайды в PDF не попадают.

## Как устроено

Один HTML-файл без сборщиков и внешних зависимостей. Шрифты Montserrat и JetBrains Mono лежат локально в `assets/fonts/`, картинки и логотипы – в `assets/`. Страница собирается из рабочей версии презентации, заметки докладчика при сборке вырезаются. Поисковым системам страница закрыта (`noindex`).
